Native Discord Events Integration

Scotch Egg integrates seamlessly with Discord's native Scheduled Events feature so you don't have to learn any special commands or web dashboards. Just create an event using Discord's built-in UI, and the bot instantly posts an interactive announcement with opt-in reminders.

100% Free

No Privileged Intents

Modern and secure. The bot relies entirely on modern slash commands and interactions.

🍓

Pi & SD-Card Friendly

Optimized for single-board computers. Uses batched disk writes to dramatically extend your Raspberry Pi's MicroSD card lifespan.

🌍

Multi-Language Support

Fully localized in English, Spanish, German, French, and Portuguese at both client slash command and server announcement levels.

🗑️

Auto-Cleanup & Archive

Keep channels tidy. Choose to completely delete or gracefully archive event announcements when they end, while public reminder messages are always deleted entirely to reduce clutter.

⏰

Custom Intervals

Tailor notification timing. Allow server administrators to configure exact times when reminders are sent (e.g., 24h, 1h, or 15m before start).
