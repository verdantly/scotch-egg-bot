A lightweight, Dockerized Discord bot that automatically announces server events and sends automated 24-hour & 1-hour reminders to users who opt-in.

Key Features

🔔

Flexible Opt-in Reminders

Choose between Private Mode (personalized DM reminders) or Public Mode (public @ mentions in the channel) for users who opt-in.

📅

Add to Calendar

Event announcements include a convenient button to instantly add the event directly to your Google Calendar.

💬

Auto-Threads

Automatically creates a dedicated discussion thread on new event announcements to encourage community engagement.

🛡️

No Privileged Intents

Modern and secure. The bot relies entirely on modern slash commands and Discord interactions.

⏱️

Automated Alerts

Sends out dynamic reminders at customizable intervals (defaults to 24h & 1h) before an event's start time.

🍓

Pi & SD-Card Friendly

Optimized for single-board computers. Uses a lightweight JSON database with minimal disk writes to protect SD cards.

Quick Start Deployment

The recommended way to deploy Scotch Egg Bot is using Docker Compose.

1. Environment Setup

Create a .env file in your project directory with your Discord credentials:

DISCORD_TOKEN=your_actual_token_here
CLIENT_ID=your_bot_client_id_here
ADMIN_USER_ID=your_discord_user_id_here

2. Initialize Database Files

Before starting Docker, create empty files so Docker maps them correctly instead of creating folders:

echo "{}" > events.json
echo "{}" > config.json

3. Start the Bot

Use Docker Compose to build and run the bot in the background:

docker compose up -d --build
Note: Don't forget to register your slash commands once! docker exec -it scotch-egg-bot node deploy-commands.js

Essential Commands

  • /settings channel Sets the announcement channel.
  • /settings mode Toggles between Public and Private DM reminder modes.
  • /upcoming Public list of upcoming events to easily opt-in.
  • /myreminders View and manage the events you are currently receiving reminders for.
